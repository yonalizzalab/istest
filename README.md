# 源泉税アシスタント (ระบบช่วยออกหนังสือรับรองการหักภาษี ณ ที่จ่าย)

เว็บไซต์สำหรับชาวญี่ปุ่นในประเทศไทย กรอกข้อมูลใบแจ้งหนี้เป็นภาษาญี่ปุ่น ระบบคำนวณภาษีหัก ณ ที่จ่าย
และออกหนังสือรับรอง 50 ทวิ บนแบบฟอร์มของกรมสรรพากรเป็นไฟล์ PDF

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (หน้าจอ กฎอัตราภาษี และการสร้าง PDF) |
| `50tawi.pdf` | แบบฟอร์ม 50 ทวิ ของกรมสรรพากร ใช้เป็นแม่แบบ ห้ามเปลี่ยนชื่อไฟล์ |
| `README.md` | ไฟล์นี้ |

## วิธีฝากบน GitHub Pages

1. สร้าง repository ใหม่บน GitHub (ตั้งเป็น Public)
2. กด **Add file → Upload files** แล้วอัปโหลด `index.html` และ `50tawi.pdf` (วางไว้ที่ระดับบนสุด ไม่ต้องอยู่ในโฟลเดอร์)
3. ไปที่ **Settings → Pages** ตรง *Build and deployment* เลือก Source = **Deploy from a branch**, Branch = **main** / **(root)** แล้วกด Save
4. รอ 1–2 นาที จะได้ลิงก์ เช่น `https://ชื่อผู้ใช้.github.io/ชื่อ-repository/`

หมายเหตุ: ถ้าเปิด `index.html` โดยดับเบิลคลิกจากเครื่อง ปุ่มดาวน์โหลด PDF จะใช้ไม่ได้ (เบราว์เซอร์ไม่ยอมให้อ่านไฟล์แม่แบบจาก `file://`)
ต้องเปิดผ่านเว็บ เช่น GitHub Pages หรือรันในเครื่องด้วยคำสั่ง `python -m http.server` แล้วเปิด `http://localhost:8000`

## ความเป็นส่วนตัว

- การคำนวณและการสร้าง PDF ทำในเบราว์เซอร์ของผู้ใช้ทั้งหมด ไม่มีเซิร์ฟเวอร์ ไม่มีการส่งหรือเก็บข้อมูลที่กรอก
- ข้อมูลผู้มีหน้าที่หักภาษี (ชื่อบริษัท เลขผู้เสียภาษี ที่อยู่) ถูกจำไว้ใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น
- สิ่งที่โหลดจากภายนอก: ไลบรารี pdf-lib 1.17.1 (cdnjs) และฟอนต์จาก Google Fonts

## จุดที่ต้องแก้เมื่อกฎหมายเปลี่ยน (ใน `index.html`)

- `const TYPES = {...}` อัตราภาษีหัก ณ ที่จ่ายแต่ละประเภท
- ข้อความเรื่อง e-Withholding Tax 1% (ใช้ได้ถึง 31 ธ.ค. 2570) ในฟังก์ชัน `judge` และท้ายหน้า
- `const R` / `const ROWR` ตำแหน่งช่องบนแบบฟอร์ม ถ้ากรมสรรพากรเปลี่ยนแบบ 50 ทวิ ต้องปรับพิกัดใหม่

## ข้อจำกัด (ขอบเขตของต้นแบบ)

- ไม่รองรับ: เงินเดือน (ภ.ง.ด.1), เงินปันผล, ค่านายหน้าและค่าลิขสิทธิ์ที่จ่ายให้บุคคลธรรมดา (อัตราก้าวหน้า)
- การจ่ายไปต่างประเทศ (ภ.ง.ด.54) แสดงเฉพาะคำเตือน ไม่ออก 50 ทวิ และไม่คำนวณตามอนุสัญญาภาษีซ้อน
- ไม่เลื่อนกำหนดยื่นแบบเมื่อตรงกับวันหยุด
- ผลลัพธ์เป็นเครื่องมือช่วย ควรให้ผู้ทำบัญชีตรวจก่อนใช้จริง
